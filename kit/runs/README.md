# runs/ — 留痕目录

一个任务一个文件，只追加不改写。格式与纪律见技能 `rp-run-log`。

```markdown
# <任务名>

| 时间 | 状态 | 说明 |
|---|---|---|
| 2026-01-01 09:00 | 开始 | 目标：…；边界：… |
| 2026-01-01 10:30 | 进度 | 单元 1/3 完成：… |
| 2026-01-01 11:20 | 结束 | 结论：…；产出：… |
| 2026-01-01 11:20 | 对账 | 源端 128 / 落盘 128，无差额 |
| 2026-01-01 11:20 | digest | 结论 + 关键数字 |
```

- `INDEX.md` 由 `node check.mjs --write-index` 生成，不手写。
- 单轮问答不写这里。
- 想把它接到别处的留痕通道？改 `.research/config.yml` 的 `paths.runs_dir` 指向那个目录，工作区里这个 `runs/` 就可以留空或删掉。
