# rp-handoff · 会话交接

一句话原则：**交接是写给"没有你今天记忆的自己"的**。

## 1. 三件套

```
tasks/<任务名>/
  AGENT.md           目标 / 边界 / 血规则         （很少改，改了就是方向变了）
  CONTEXT_INDEX.md   当前步 / 下一步 / 文件地图    （每步更新）
  handoff/current.md 本次会话的实际进展与坑       （收工前写，留最近 3 份）
```

增量的历史归档到 `handoff/<YYYYMMDD-HHMM>.md`，`current.md` 永远是最新一份。

## 2. CONTEXT_INDEX.md 的格式（必须短，一屏内）

```markdown
# 当前状态

## 当前步
第 3/7 步：正在做 X（做到哪、卡在哪）

## 下一步
1. 具体动作（含目标文件路径）
2. …

## 文件地图
- `output/xxx.md` — 主交付，写到第 4 节
- `data/yyy.csv` — 已清洗，128 行
- `runs/zzz.md` — 留痕

## 血规则（踩过的坑，别再踩）
- 不要用 A 方法读这个大文件（会 OOM）
- B 接口返回 GBK，先转码
```

## 3. current.md 的格式

```markdown
# 交接：<任务名> @ <日期 时间>

## 结论/现状
（三句话内说清现在是什么状态）

## 已确认的事实
- …

## 未决问题
- …（需要人拍板的写明选项与推荐）

## 下一步第一个动作
（具体到文件与命令）
```

## 4. 写好交接的自检

- [ ] 只有"下一步第一个动作"是可执行的具体动作吗？
- [ ] 有没有把"暂定的猜测"写成"已确认的事实"？（猜测要标"待验证"）
- [ ] 文件地图里的路径都真实存在吗？
- [ ] 需要用户拍板的，有没有给你的推荐选项？

## 5. 反模式

- 交接写成散文，读完还不知道下一步做什么。
- 把整段对话粘进交接（等于没压缩）。
- 只写"做了什么"，不写"下一步"。
- 血规则事后补——踩坑当场写才有细节。
